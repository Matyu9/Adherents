# Guide d'utilisation

Ce guide décrit Adhérents écran par écran, pour chaque personne qui s'en sert : les **familles**, les **professeurs**, le **secrétariat** (rôle Gestionnaire) et les **administrateurs**. Chaque section dit qui peut faire quoi ; le détail des droits est [à la fin](#qui-peut-faire-quoi).

Pour le fonctionnement interne, voir [annuaire.md](annuaire.md), [catalogue.md](catalogue.md) et [inscriptions.md](inscriptions.md).

## Pour les familles

### Se connecter

Le compte est créé par le secrétariat, depuis votre fiche d'adhérent. Vous recevez une **invitation** par email : le lien permet de choisir votre mot de passe. Ensuite, connectez-vous avec votre adresse et ce mot de passe.

- **Un compte par adulte.** Un enfant de moins de 16 ans n'a pas de compte : son responsable gère sa fiche depuis le sien. À partir de 16 ans, un élève peut avoir son propre compte, avec l'accord d'un responsable légal.
- **Mot de passe oublié ?** Le lien sous le formulaire de connexion envoie un email de réinitialisation.
- Le même compte ouvre les autres applis de l'association, comme l'Inventaire.

Si, une fois connecté, **Mon espace** n'apparaît pas dans le menu, votre compte n'est pas encore relié à votre fiche : contactez le secrétariat.

### Mon espace

**Menu → Mon espace.** On y trouve ce que l'association sait de votre foyer :

- l'**adresse** et les **téléphones** du foyer ;
- le **prélèvement** : vos coordonnées bancaires, masquées (seuls les quatre derniers chiffres de l'IBAN), et si un mandat est signé ;
- chaque **membre du foyer**, avec ses adhésions saison par saison et ses **cours** (jour, horaire, salle, professeur) ;
- le **matériel prêté** à chacun, s'il est suivi dans l'Inventaire ;
- vos **dossiers d'inscription** et leur statut ;
- les **engagements** donnés (droit à l'image, règlement intérieur…), datés.

**Plusieurs foyers ?** Un parent présent dans deux familles (famille recomposée) voit les deux.

**Un élève de 16 ans ou plus** avec son propre compte voit seulement ses cours et le matériel qui lui est prêté, pas le reste du foyer.

**Rien ne se modifie ici.** Pour corriger une information, passez par votre dossier d'inscription pendant une campagne, ou contactez le secrétariat.

### Inscrire ou réinscrire ses enfants

Pendant une campagne d'inscription, le tableau de bord l'annonce, et une relance arrive chaque semaine tant que le dossier n'est pas envoyé.

1. **Menu → Inscriptions**, puis **Commencer le dossier** (ou **Continuer**).
2. Le dossier est **pré-rempli** avec ce que l'association sait de votre foyer. Les cours de l'an dernier sont déjà proposés pour la nouvelle saison : même discipline, même niveau. Vérifiez chaque partie.

**1. Le foyer.** Adresse, téléphone du domicile, et un ou deux responsables (nom, email, téléphone, lien avec les élèves). Au moins une adresse email et un téléphone sont nécessaires.

**2. Les élèves et leurs cours.** Pour chaque élève, cliquez **Modifier** :

- cochez ou décochez **Inscrire cet élève cette saison** (un enfant qui ne revient pas reste dans la liste, décoché) ;
- vérifiez son identité, sa catégorie et sa classe ;
- choisissez ses **cours**. Un cours **complet** est grisé : indiquez votre souhait dans la case **Souhaits, contraintes d'horaire**, le secrétariat vous recontactera ;
- répondez aux consentements demandés pour lui (droit à l'image…).

Pour ajouter un enfant, ou vous inscrire vous-même, utilisez **+ Ajouter un élève** sous la liste.

**3. Engagements du foyer.** Les consentements demandés pour tout le foyer, comme le règlement intérieur. Ceux marqués « obligatoire » doivent être acceptés pour envoyer le dossier.

**Prélèvement (facultatif).** Pour payer la cotisation par prélèvement, recopiez l'IBAN de votre RIB. Il est vérifié, puis chiffré aussitôt : ensuite, seuls ses quatre derniers chiffres s'affichent. Le mandat de prélèvement vous sera proposé par le secrétariat.

**Envoi.** Tant qu'il manque quelque chose, la liste en bas du dossier l'indique. Une fois tout rempli, cochez **Je certifie l'exactitude de ces informations**, ajoutez un message si besoin, puis **Envoyer le dossier**.

**Et ensuite ?**

- Le secrétariat relit le dossier. Vous êtes prévenu(e) par une notification, et par email si l'envoi d'emails est configuré.
- S'il manque quelque chose, le dossier revient **à corriger**, avec un message : corrigez, puis renvoyez-le.
- Une fois **validé**, l'inscription est enregistrée et apparaît dans Mon espace.

Un dossier envoyé ne se modifie plus, sauf s'il vous est renvoyé. Après la clôture de la campagne, il ne se modifie plus du tout : contactez le secrétariat.

### Nouvelle famille : s'inscrire sans compte

Si la campagne accueille les nouvelles familles, le secrétariat diffuse l'adresse du formulaire (sur le site, par affiche…).

1. Indiquez votre **adresse email**, puis **Recevoir le lien**.
2. Ouvrez l'email reçu et cliquez **Ouvrir mon dossier**. Le lien reste valable 30 jours : gardez l'email pour revenir compléter le dossier.
3. Remplissez le dossier comme ci-dessus : le foyer, les responsables, les élèves et leurs cours. Puis envoyez-le.

Le lien sert autant de fois que nécessaire pendant 30 jours. Si vous en redemandez un, c'est le nouveau qui compte : l'ancien ne sert plus. Pas d'email après quelques minutes ? Regardez dans les courriers indésirables, puis recommencez.

Une fois le dossier validé, le secrétariat peut vous créer un compte pour accéder à Mon espace.

## Pour les professeurs

**Menu → Mes élèves** (le lien apparaît quand votre compte est relié à votre fiche de professeur).

Pour la saison en cours, ou une autre choisie en haut à droite, la page liste **vos cours** et, pour chacun, **les élèves inscrits**, leur âge et leurs **responsables** (nom, téléphone, email), pour les joindre.

Vous ne voyez que vos élèves, et rien d'autre de l'annuaire. Un professeur qui est aussi parent retrouve son foyer dans **Mon espace**.

## Pour le secrétariat

Le rôle **Gestionnaire** gère l'annuaire, le catalogue et les inscriptions. Il doit utiliser la double authentification (code à 6 chiffres d'une appli comme Google Authenticator), car il lit des données personnelles. Sa session se ferme après 2 heures sans activité.

### Les saisons

**Annuaire → Saisons.** Une saison (« 2027-2028 ») a une date de début et de fin.

- **La saison en cours se choisit à la main** (**Mettre en cours**), elle ne dépend pas de la date : la réinscription à la saison suivante s'ouvre pendant que l'actuelle tourne encore.
- Une saison qui a des adhésions, des cours ou des campagnes ne se supprime pas.

### L'annuaire

**Annuaire → Personnes** et **Foyers.** Une personne a **une seule fiche**, quels que soient ses rôles (élève, responsable, professeur). Le **foyer** est le payeur : adresse, IBAN et cotisations s'y rattachent.

- **Rechercher** : nom, prénom ou email, sans se soucier des accents. Les filtres montrent les élèves de la saison, les anciens adhérents ou les fiches archivées.
- **Un foyer** a un responsable 1, éventuellement un responsable 2, et des personnes à charge. Un adulte seul est le responsable 1 de son propre foyer.
- **Doublons** : **Fusionner un doublon**, depuis l'une des deux fiches. L'écran montre les différences et demande quoi garder ; foyers, téléphones, adhésions, cours et consentements s'additionnent.
- **Archiver** plutôt que supprimer : une fiche archivée sort des listes, son historique reste.
- **Comptes** : la création d'un compte depuis une fiche et le rattachement des comptes existants demandent aussi le droit de gérer les comptes, réservé par défaut à l'administrateur (voir [plus bas](#comptes-des-familles)).

La fiche d'une personne montre aussi l'historique de ce qui l'a concernée (journal).

### Le catalogue

**Menu → Catalogue.** Il a trois onglets.

**Disciplines, niveaux et lieux.** Ces listes valent pour toutes les saisons : types de discipline, disciplines, niveaux (dans l'ordre, cycle 1 avant cycle 2), sites et leurs salles.

- **Les types de discipline sont les vôtres.** Aucun n'existe au départ : créez ceux qui conviennent à votre association (« Instrument » et « Pratique collective » pour une école de musique, « Sport collectif » ou « Atelier » ailleurs). Ils regroupent les disciplines dans les listes, dans l'ordre que vous leur donnez. Une discipline peut ne pas avoir de type.

- Deux noms qui ne diffèrent que par un accent sont refusés : « Flute » et « Flûte » sont la même discipline.
- Ce qui a déjà servi ne se supprime pas : **Archiver** le retire des choix pour les nouveaux cours, sans toucher aux saisons passées. **Rouvrir** le remet.
- Archiver un site ferme toutes ses salles.

**Cours.** Les cours de la saison choisie en haut à droite. Un cours, c'est :

- une **discipline**, un **niveau** (facultatif) et un **groupe** pour distinguer deux cours semblables (« groupe A », « ados ») ;
- un **professeur**, ou « À trouver » ;
- un **jour** et un **horaire**, une **salle** ;
- un **effectif maximum**, ou rien pour ne pas limiter ;
- la case **Cours individuel**, quand chaque élève passe à son heure dans le créneau du professeur ;
- la case **Complet**, pour ne plus le proposer aux familles.

**+ Nouveau cours** en crée un ; **Dupliquer** part d'un cours existant pour en créer un autre groupe. La colonne **Effectif** montre les inscrits sur le maximum : un cours plein est marqué **complet**.

- **Chevauchements** : deux cours le même jour, aux mêmes heures, dans la même salle ou avec le même professeur, sont signalés en rouge. Ce n'est qu'un avertissement : deux petits groupes peuvent partager une grande salle.
- **Professeur parti** : un professeur n'est proposé que pour les saisons où il est là (d'après son arrivée et son départ). Un cours dont le professeur part en cours de saison est marqué « parti le … », pour lui trouver un remplaçant.
- Un cours qui a des élèves ne se supprime pas : cochez **Complet** à la place.

**Professeurs.** Les disciplines enseignées par chaque professeur, saison par saison. Confier un cours à un professeur ajoute sa discipline d'office ; à l'inverse, on ne peut pas lui retirer une discipline dont il a encore un cours.

### Les élèves d'un cours

**Catalogue → cliquez sur un cours.** La page montre ses élèves, leurs responsables et leur date d'arrivée, l'effectif face au maximum, et en bas les élèves partis en cours d'année.

- **Télécharger la liste** donne un fichier à ouvrir dans un tableur.
- **Écrire aux familles** ouvre votre messagerie avec les adresses des responsables en copie cachée.

En cours d'année, le secrétariat peut :

- **+ Inscrire un élève** : choisissez-le parmi les adhérents de la saison, et la date de son premier cours. On peut aussi partir de sa fiche : **Annuaire → la personne → Adhésions → + Inscrire à un cours**.
- **Changer de cours** : l'élève quitte son groupe et rejoint l'autre à la date indiquée. Les deux cours gardent la trace du passage.
- **Abandon** : l'élève quitte ce cours seulement ; il reste adhérent et garde ses autres cours. S'il quitte l'association, passez plutôt son adhésion en « Abandon » sur sa fiche.

Un cours complet accepte quand même l'élève, avec un avertissement.

**Cours individuel.** Sur la page du cours, chaque ligne a une heure de passage et une durée. Les élèves se rangent dans l'ordre de la journée et les plages libres s'affichent en haut. Un passage qui déborde du créneau, qui chevauche celui d'un autre élève ou un autre cours du même élève est signalé en rouge. Le professeur voit ces heures dans **Mes élèves**, la famille dans **Mon espace**.

**La cotisation n'est jamais recalculée toute seule.** Si celle du foyer était déjà calculée, elle est marquée **à revoir** dans **Tarifs → Cotisations**, avec la liste des changements. Recalculez-la, ou indiquez qu'il n'y a rien à changer.

### Préparer une nouvelle saison

1. **Annuaire → Saisons → + Nouvelle saison** (sans la mettre en cours).
2. **Catalogue → Copier une saison** : choisissez la saison d'origine et la nouvelle. L'aperçu montre ce qui sera repris, laissé de côté ou à compléter, **sans rien écrire**.
   - un cours d'une discipline archivée n'est pas recopié ;
   - un niveau ou une salle archivés sont laissés vides ;
   - un professeur parti est remplacé par « à trouver » ;
   - un cours fermé à la main est rouvert.
3. **Copier**, puis ajustez : nouveaux cours, horaires, professeurs. La copie ne remplit qu'une saison encore vide.
4. Ouvrez la campagne d'inscription (ci-dessous).
5. À la rentrée, **Mettre en cours** la nouvelle saison.

### Les campagnes d'inscription

**Menu → Campagnes → + Nouvelle campagne.**

- **Saison** et **titre**, vu par les familles (« Réinscriptions 2027-2028 ») ;
- **ouverture** et **clôture**, à la minute près : les familles ne peuvent modifier ou envoyer leur dossier qu'entre les deux ;
- **Accueillir aussi les nouvelles familles** : ouvre un formulaire public. Son adresse s'affiche sur la page de la campagne, à diffuser ;
- **Message aux familles** : affiché en tête de chaque dossier (pièces à prévoir, dates…).

Puis, sur la page de la campagne, **+ Ajouter un consentement** pour chaque engagement à demander :

- **pour chaque élève** (droit à l'image) ou **pour le foyer** (règlement intérieur) ;
- **obligatoire** ou non : sans un consentement obligatoire, le dossier ne part pas.

Le texte du consentement est gardé tel quel dans chaque réponse : s'il change plus tard, on sait toujours ce qui a été accepté. Une fois des dossiers envoyés, un consentement ne se retire plus.

**Pendant la campagne :**

- la page de la campagne compte les dossiers par statut ;
- chaque semaine, une relance part vers les responsables qui ont un compte : foyers d'élèves de l'an dernier sans dossier, dossiers commencés mais pas envoyés, dossiers à corriger.

### Relire et valider les dossiers

**Campagnes → la campagne → Dossiers**, filtré sur **Soumis**. Un dossier montre :

- **ce que la validation changera dans l'annuaire**, champ par champ (avant, après) : nouvelle adresse, nouveau téléphone, nouvel élève, cours choisis, IBAN (masqué) ;
- les élèves et leurs cours, avec le nombre d'inscrits de chaque cours ;
- les réponses aux consentements, et le message éventuel de la famille.

Deux décisions :

- **Renvoyer à la famille**, avec un message qui dit quoi corriger. La famille est prévenue, corrige et renvoie.
- **Valider et mettre à jour l'annuaire.** Le dossier est recopié dans l'annuaire :
  - fiches et foyer mis à jour (ou créés pour une nouvelle famille) ;
  - adhésion de la saison et inscription à chaque cours ;
  - consentements, datés de l'envoi ;
  - IBAN ajouté au foyer, sauf s'il y était déjà.

  La famille est prévenue.

**L'annuaire ne change qu'à ce moment-là.** Tant qu'un dossier n'est pas validé, ce que la famille a saisi reste dans le dossier.

À la validation, l'écran signale :

- un cours devenu **complet** entre-temps (l'élève y est inscrit quand même : à vous de voir) ;
- un IBAN déjà présent sur un autre foyer.

**Nouvelle famille** : avant de valider, vérifiez dans l'annuaire qu'elle n'y est pas déjà. Sinon, fusionnez les fiches ensuite.

### Reporter dans le logiciel de gestion

Tant que le logiciel de gestion reste la référence, chaque dossier validé y est ressaisi.

1. **Campagnes → la campagne → Report** : la liste des dossiers validés pas encore reportés.
2. **Fichier sans IBAN** : une ligne par changement, dossier par dossier (fichier CSV, qui s'ouvre dans un tableur).
3. Le trésorier (droit aux coordonnées bancaires) a aussi **Fichier avec les IBAN en clair**, après avoir ressaisi son code de double authentification. **Supprimez ce fichier, corbeille comprise, dès la saisie terminée** : l'appli ne peut plus le protéger.
4. Une fois la saisie faite, cochez les dossiers et **Noter comme reportés**. On peut aussi le faire dossier par dossier.

Chaque téléchargement du fichier avec IBAN est inscrit au journal. Le format du fichier est provisoire : il sera adapté au modèle d'import du logiciel de gestion.

## Pour les administrateurs

L'administrateur a tous les droits. Les sections ci-dessous concernent ce qui lui est réservé par défaut ; on peut donner ces droits à d'autres rôles dans **Rôles**.

### Comptes des familles

- **Créer un compte** : depuis la fiche d'un adulte qui a une adresse email, **Créer son compte et l'inviter**. La personne reçoit l'invitation par email. Pour un élève de 16 ou 17 ans, confirmez qu'un responsable légal a donné son accord.
- **Relier les comptes existants** : **Annuaire → Rattachement** propose, pour chaque compte sans fiche, les fiches qui lui ressemblent (même email, même nom). Vérifiez avant de valider : l'email seul ne suffit pas, une adresse est souvent partagée dans une famille.
- Tant qu'un compte n'est pas relié à la fiche d'un responsable, la famille ne voit ni **Mon espace** ni son dossier d'inscription.

### Professeurs et contrats

**Annuaire → Professeurs** (droit « Gérer les professeurs »). On ne devient professeur que d'ici, jamais depuis une fiche d'adhérent.

- **+ Nouveau professeur** crée la fiche et le contrat. Un parent ou un élève adulte qui enseigne garde sa fiche : cherchez-le dans « Il est déjà dans l'annuaire ? ».
- Le **contrat** (statut, arrivée, départ, email professionnel) n'est visible que d'ici.
- **Un départ s'indique par sa date** : la fiche et l'historique restent. Le professeur n'est plus proposé pour les saisons suivantes, et la copie de saison laisse ses cours « à trouver ».
- La fiche d'un professeur montre ses disciplines et ses cours de la saison en cours.

### Coordonnées bancaires

Voir et modifier les IBAN demande le droit « Voir et modifier les coordonnées bancaires » et le **mode sécurisé** : on ressaisit son code de double authentification, et le mode dure quelques minutes. Chaque lecture d'un IBAN en clair est inscrite au journal. Ailleurs, les IBAN restent masqués.

### Relier l'Inventaire à l'espace adhérent

Pour que les familles voient le matériel prêté dans **Mon espace**, à faire une fois :

1. **Ici, Applications → Inventaire → Modifier** : cochez « Peut récupérer la liste des comptes… ». L'Inventaire peut alors lire la liste des personnes de l'annuaire (nom, année de naissance, sans email ni adresse).
2. **Dans l'Inventaire, Personnes → Rattacher à l'annuaire → Récupérer les personnes depuis Adhérents.** Chaque fiche de l'Inventaire (élève, musicien) est reliée à sa personne d'Adhérents. Seule une fiche déjà reliée au même compte de connexion est cochée d'office ; **un même nom ne suffit pas** : vérifiez (année de naissance, pupitre, classe) avant de cocher.
3. **Sur le serveur de l'Inventaire**, `flask jeton-espace-adherent` crée un compte de service qui ne peut que lire les prêts, et affiche son jeton une seule fois.
4. **Sur le serveur d'Adhérents**, renseignez `INVENTAIRE_API_URL` et `INVENTAIRE_API_TOKEN`, puis redémarrez (voir [configuration.md](configuration.md#espace-adhérent--le-matériel-prêté)).

Refaites l'étape 2 quand de nouveaux élèves arrivent : les fiches déjà reliées sont simplement signalées. Si le jeton a pu fuiter, relancez l'étape 3 (l'ancien jeton ne sert plus) et recopiez le nouveau.

### Conservation des données

**Annuaire → Conservation** (droit « Fixer la durée de conservation et anonymiser »).

1. **Fixez la durée**, en saisons. Tant qu'elle n'est pas choisie, rien n'est proposé : c'est une décision de l'association, à inscrire au registre des traitements.
2. L'écran liste alors les **personnes à anonymiser** : sans adhésion depuis ce nombre de saisons, sans compte, sans profil de professeur, et dont aucun membre du foyer n'a d'adhésion récente.
3. Décochez celles à garder, puis **Anonymiser**. **C'est définitif.**

L'anonymisation efface :

- le nom, les coordonnées, les téléphones, les numéros du logiciel de gestion, les consentements et les observations ;
- le jour et le mois de naissance (l'année reste) ;
- le texte du journal qui concernait la personne.

Ses adhésions et inscriptions passées restent, sans nom, pour les statistiques. Quand tout un foyer est anonymisé, il perd aussi son adresse, ses IBAN, ses mandats et ses dossiers.

Le même écran supprime les **anciens dossiers d'inscription** des campagnes trop anciennes.

## Le calendrier d'une saison

| Quand | Qui | Quoi |
|---|---|---|
| Printemps | Secrétariat | Créer la saison suivante, copier le catalogue, l'ajuster |
| Avant l'ouverture | Secrétariat | Créer la campagne, ses dates et ses consentements ; diffuser le formulaire des nouvelles familles |
| Pendant la campagne | Familles | Vérifier, choisir les cours, envoyer le dossier |
| Pendant la campagne | Secrétariat | Relire, renvoyer ou valider ; reporter dans le logiciel de gestion |
| Toutes les semaines | (automatique) | Relances des dossiers non envoyés |
| Rentrée | Secrétariat | Mettre la nouvelle saison en cours ; fermer les cours complets ; trouver les professeurs « à trouver » |
| Toute l'année | Secrétariat | Arrivées, changements de cours et abandons ; revoir les cotisations marquées « à revoir » |
| Une fois par an | Administrateur | Anonymiser les anciens adhérents, supprimer les anciens dossiers |

| Campagnes : créer, relire, valider, fichier de report | | | ✓ | ✓ |

Ce tableau décrit les rôles de base. Les droits de chaque rôle se cochent dans **Rôles** : on peut par exemple créer un rôle « Trésorier » avec les coordonnées bancaires, ou un rôle « Direction » qui consulte le catalogue et les campagnes sans les modifier.

## Questions fréquentes

**Une famille ne trouve pas son dossier.** Son compte doit être relié à la fiche d'un responsable du foyer : voir [Comptes des familles](#comptes-des-familles). Un enfant de moins de 16 ans n'a pas de compte : c'est le parent qui ouvre le dossier.

**Un parent séparé veut son propre dossier.** Un dossier vaut pour un foyer. Si les deux parents sont responsables du même foyer, ils partagent le même dossier. S'ils ont chacun leur foyer, chacun a le sien.

**Un cours est complet mais il faut ajouter un élève.** À la validation d'un dossier, un cours complet n'est qu'un avertissement : l'élève y est inscrit quand même. Vous pouvez aussi augmenter l'effectif maximum du cours.

**La famille s'est trompée après l'envoi.** Renvoyez-lui le dossier (**Renvoyer à la famille**) avec un message. Après la validation, corrigez directement dans l'annuaire.

**Le dossier d'une nouvelle famille concerne une famille déjà connue.** Validez-le, puis fusionnez les fiches et les foyers en double depuis l'annuaire : adhésions, cours, consentements et dossiers suivent.

**Mon espace dit « Matériel prêté : indisponible ».** L'Inventaire ne répond pas, ou le jeton n'est plus valable. Le reste de la page marche ; voir [Relier l'Inventaire](#relier-linventaire-à-lespace-adhérent).

**Un matériel prêté n'apparaît pas.** La fiche de l'élève dans l'Inventaire n'est pas encore reliée à l'annuaire (**Personnes → Rattacher à l'annuaire**, dans l'Inventaire), ou le prêt n'est pas une garde validée ou en cours.
